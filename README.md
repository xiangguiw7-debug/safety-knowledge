# 安规与可靠性知识课堂（教学网站原型）

面向电气电子工程师的教学网站：电气间隙、爬电距离、雷击浪涌、耐压测试四大模块，附带交互式计算器和 8 题自测。

## 运行方式

直接双击 `index.html` 即可在浏览器中浏览全部页面。

若要体验完整的 PWA 离线功能（Service Worker 在 `file://` 下不生效），在项目根目录启动本地服务器：

```powershell
python -m http.server 8000
```

然后访问 `http://127.0.0.1:8000`。也可以双击 `start.ps1` 自动启动。

## 内容说明

- 所有表格与计算器数值均为**教学简化取值**，与 IEC 60664-1 的查表逻辑一致，但不能替代标准原文。
- 正式产品设计、测试与认证请依据最新版标准：
  - IEC 60664-1 绝缘配合
  - IEC 62368-1 / IEC 60950-1 音视频与 IT 设备
  - IEC 60335-1 家用电器
  - IEC 60601-1 医疗设备
  - IEC 61000-4-5 / GB/T 17626.5 浪涌抗扰度

## 行业筛选

新增行业筛选页（pages/industries.html），覆盖 27 个行业：

- 灯具照明、消费电子、家用电器、医疗设备、工业机械
- 电动工具、电源与充电器、电池与储能、汽车电子、IT 与通信

每个行业卡片包含：适用标准、重点学习模块、典型测试项目、常见设计坑，以及指向本站四个核心章节的链接。数据在 assets/js/industry-data.js 中，新增行业只需在数组里加一项；尚未有独立章节的学习主题会跳转到补充知识速览页（pages/knowledge.html）。

标准文件入口页（pages/standards.html）提供官方检索渠道链接与内容可信度说明；行业页和行业卡片的“适用标准”都会跳转到该页对应条目。

计算工具已改版：场景预设、滑块参数、爬电/间隙双结果、PCB 间距可视化与达标判断，脚本为 assets/js/calculator-v2.js。
