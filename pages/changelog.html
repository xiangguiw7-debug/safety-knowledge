v1.4.0（2026-08-14）

费曼学习法、导航重构、返回与状态恢复、手机同步与开源准备

  • 🧠 费曼学习法：答题测验新增「自测 | 费曼学习法」双模式——抽一张知识卡，用自己的话讲给小白听，对照参考讲解自动标出「卡壳点」，复盘保存并支持复习对比（已攻克 / 仍卡住 / 本次新增），返回页面自动恢复模式、卡片与草稿；
  • 🧭 导航重构：顶部导航统一为「首页 / 学习 / 测试 / 认证 / 行业 / 答题测验 / 资源」，行业筛选晋升一级入口，产品品类知识归入行业；移动端底部导航全站统一；
  • 🔙 返回与状态恢复：新增全局「← 返回上一页」按钮；认证向导、项目工坊、标准对比、计算工具在跳转后自动恢复上次进度/参数；知识卡与章节页的「计算工具」链接直达对应计算器（#tool-xxx 精准定位）；
  • 📲 手机 / 电脑同步：数据备份页新增「复制同步文本 + 合并导入」，按类型合并去重，学习进度、笔记、错题、费曼记录可在两台设备间转移；
  • 🔧 全站修复：防电击分组 electric/shock 词汇统一；语义错链修复（电弧引燃、射频暴露/SAR、HAI/HWI/RTI 等指向错误卡片）；修复导航栏切换闪烁、深色主题首帧闪烁、卡片淡入闪烁；3 处页面 HTML 结构不平衡；题库与案例计数口径修正；答题页重复脚本移除；
  • 🚀 开源上线准备：MIT + CC BY 4.0 双许可、README 重写、CI 检查工作流（链接/结构自动校验）、sitemap/robots 更新、旧版备份移出版本控制。

v1.1（2026-08-12）

自 v1.0 以来的全部内容、工具、交互与体验更新

📚 内容体系

  • 七大安全因素深度页补齐：新增能量、防火、热量、机械、辐射、化学 6 个深度页，加上防电击体系形成完整学习线；
  • 工程专题：PCB 安规设计指南、元器件安全、环境与可靠性试验、标签与说明书、产品类别结构图、设计师必知安规、岗位化学习路径、MOPP/MOOP、双重绝缘判定、IoT 网络安全；
  • 深度页：泄漏电流、接地与等电位、SELV/TNV、绝缘配合总览、雷击浪涌等；
  • 案例与问答：25 个可筛选整改案例 + 10 个常见问题，案例全部关联标准条款 / SOP / 工具 / 知识卡；
  • 行业扩充：行业筛选达 27 个，新增智能家居/IoT、机器人/AGV、充电桩/电动车、无人机/玩具、电动自行车/滑板车等；
  • 术语表：49 条术语，新增英文对照列并链到对应知识；
  • 导航与资源中心：统一入口页 + 全站地图，顶部与底部导航统一为“首页 / 导航 / 学习 / 测试 / 认证 / 答题测验”；
  • 全球认证真实地图：OpenStreetMap 全球底图（免 Key）集成到认证页默认视图，89 个国家/地区标记，移除 3D 地球仪；
  • 四步学习路径：首页“学 → 测 → 考 → 查”流程卡重设计。

🧠 知识卡与学习

  • 知识卡改版：主题目录 + 独立详情页（大字号、完整规则、标准徽章、工具/深读链接、知识链路、上一张/下一张导航），旧锚点自动跳转；
  • 知识卡全量审计补强：31 张卡补齐规则表 / 误区 / 深读入口，覆盖 RoHS 十项限值、激光等级、ISO 13857 开口距离、车载瞬态波形、RG 分级、Ex 型式、CTI 材料组、SELV/接地等；
  • 温升基准对照表：60335 25°C / 61010 40°C / 60034 40°C / 60598 10–30°C / 18487 40°C，含换算方法；
  • EMC 课程重构：按 EMI（电磁干扰/发射）与 EMS（电磁敏感度/抗扰）两大分支组织，补齐辐射抗扰 RS（IEC 61000-4-3）与传导抗扰 CS（IEC 61000-4-6）；
  • 知识卡索引手风琴：内容地图按分类展开、搜索联动，区分知识卡片与深度页直达；
  • 修复分组缺卡：防电击 5 张卡、框架/认证流程/医疗专项空分组；激光安全与医疗辐射“待补充”卡片补全。

🧪 测试与 SOP

  • 测试中心重设计：分类卡片容器 + 图标/类型徽标项目小卡（SOP / 知识 / 课程 / 工具 / 设备），分类筛选保留；
  • 测试中心分类整合：电气安全 / 环境可靠性 / EMC / 防火 / 防护等级 / 电池 / 工具；
  • SOP 中心：62 份执行级 SOP，支持按行业与类别筛选；
  • 针焰参数补全：火焰 12mm±1mm、45° 施加、铺底层约 200mm±5mm、校准 100→700°C 约 23.5s，知识卡/SOP/设备页同步；
  • 温升 SOP 同步：先确认基准环境温度；接地、防火材料、电池知识卡内容同步到对应 SOP；
  • 可靠性测试中心：温度类新增“温升测试（安规发热试验）”，支持按行业筛选，修复户外计划防尘/防水失效引用。
