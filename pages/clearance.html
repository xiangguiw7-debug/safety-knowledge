电气间隙（Clearance）详解

目标：学完这一章，你能独立完成“定过电压类别 → 查冲击耐受 → 查表 → 海拔修正”的完整闭环。

1. 定义：间隙管的是“空气击穿”

电气间隙（clearance）是两个导电部件之间通过空气或其他气体介质的最短直线距离，防止电压把空气击穿、发生闪络。

空气的击穿电压不是常数：它随电极形状（尖端效应）、气压、湿度、海拔变化。标准用“冲击耐受电压”和“海拔修正”把这些问题统一成可查表的形式。

2. 为什么看“峰值 / 冲击电压”，而不是 220V

空气击穿由瞬时电压峰值决定，不是有效值。220V 市电的峰值约 311V，但电网上的暂态过电压（雷击感应、开关操作）会在几个微秒内叠加出数千伏。标准用 1.2/50μs 冲击波模拟这种瞬态。

  • 有效值（RMS）描述持续发热，用于爬电距离和耐压；
  • 峰值/冲击电压描述瞬时击穿风险，用于电气间隙；
  • 设备安装位置越靠近电网进线，遭受的冲击越强，这就是过电压类别。

判断方法：看产品接到电网的位置，而不是产品大小。同一个开关电源，装在插头后面是类别 Ⅱ，装在配电柜里就是类别 Ⅲ。

4. 查表完整流程（六步）

  1. 定系统标称电压：120V / 230V / 400V（三相取线电压）；
  2. 定过电压类别：Ⅰ–Ⅳ，按安装位置；
  3. 得冲击耐受电压：查类别表（或由标准给出）；
  4. 定绝缘类型：基本/附加/加强（附加同基本，加强 ≈ 2×）；
  5. 查最小间隙：按冲击耐受电压查表；
  6. 海拔修正：海拔 > 2000m 时乘以修正系数。

怎么用

修正后间隙 = 查表值 × 系数。例如 3000m 海拔下，2500V 冲击的基本绝缘 = 2.0 × 1.14 ≈ 2.3mm。

5. 完整示例

示例 A：230V 插头连接的 II 类设备

  1. 系统 230V，插头连接 → 类别 Ⅱ → 冲击耐受 2500V；
  2. 基本绝缘查表 → 2.0mm；加强绝缘 → 4.0mm；
  3. 海拔 ≤2000m → 结论：加强绝缘间隙 ≥ 4.0mm。

示例 B：120V 美国市场产品

  1. 系统 120V，插头连接 → 类别 Ⅱ → 冲击耐受 1500V；
  2. 基本绝缘 → 1.0mm；加强绝缘 → 2.0mm；
  3. 结论：基本绝缘间隙 ≥ 1.0mm（比 230V 产品宽松约一半）。

示例 C：400V 工业柜，使用海拔 4000m

  1. 系统 400V，固定安装 → 类别 Ⅲ → 冲击耐受 6000V；
  2. 基本绝缘查表 → 5.5mm；
  3. 海拔 4000m 系数 1.29 → 5.5 × 1.29 ≈ 7.1mm → 设计按 ≥ 7.2mm。

三个例子都能在计算工具里复现（示例 C 记得把海拔滑块拉到 4000m）。

6. 结构设计技巧

  • PCB 走线：高压与低压区域拉开距离；焊盘、过孔、走线拐角都算导电部件，不能只量“直线走线”的间距；
  • 开槽对间隙无效：PCB 开槽只增加爬电路径，空气直线距离不变；
  • 元件引脚：立式元件引脚折弯后可能缩短与相邻元件的直线距离，装配图要复核；
  • 变压器：初次级绕组间用挡墙胶带增加实际空气路径，引脚间距也要查；
  • 连接器：端子排相邻脚距按冲击电压查表，必要时选高间距规格；
  • 散热器：散热器与带电件、机壳之间都要量间隙，注意螺丝和安装孔；
  • 海拔与密封：高原产品按系数放大；密封外壳内部气压变化同样影响击穿，不能默认“密封就安全”。

7. 常见误区

  • “220V 产品间隙按 220V 算”——要看冲击耐受（峰值/瞬态），不是有效值；
  • “爬电够了间隙一定够”——间隙和爬电是两套表，雷电冲击场景下间隙可能更严；
  • “开槽能救间隙”——开槽只救爬电；
  • “阻焊层算绝缘距离”——阻焊层既不算间隙也不算爬电（除非涂层试验）；
  • “海拔只影响爬电”——恰恰相反，海拔修正是间隙的专属；
  • “类别按产品功率定”——按接入电网的位置定。
