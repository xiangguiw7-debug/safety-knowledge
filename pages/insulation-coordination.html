绝缘配合总览（IEC 60664-1）

爬电和间隙不是两张孤立表格，而是一条参数链：电压 → 环境 → 材料 → 绝缘类型 → 距离。

1. 绝缘配合是什么

绝缘配合 = 在目标使用环境下，把绝缘系统设计得能承受预期电压（持续、暂态、冲击）和污染，保证寿命内不失效。查表只是最后一步。

2. 两条查表路径

路径输入参数输出去哪查
电气间隙系统电压 + 过电压类别 → 冲击耐受 → 海拔修正空气最短距离间隙深度页
爬电距离工作电压 + 污染等级 + 材料组（CTI）+ 绝缘类型沿绝缘表面距离爬电深度页

3. 参数链

参数影响什么典型取值
系统电压过电压类别 → 冲击耐受 → 间隙120 / 230 / 400V
工作电压爬电距离查表电压宽压产品按 250V 档
过电压类别间隙的冲击耐受I（SPD 后）/ II（插头）/ III（固定）/ IV（进线）
污染等级爬电与间隙的环境系数1 密封 / 2 室内 / 3 工业潮湿
材料组（CTI）爬电距离列I ≥600 / II 400–600 / IIIa 175–400 / IIIb 100–175
绝缘类型距离倍率基本 1× / 附加 1× / 加强 ≈2× / 功能按失效后果
海拔间隙修正2000m 以上放大

4. 五步查表流程

  1. 确定产品类别与供电方式（I/II/III）；
  2. 确定系统电压与过电压类别（间隙用）和工作电压（爬电用）；
  3. 判断污染等级与材料组（CTI，看供应商报告）；
  4. 确定绝缘类型（基本/附加/加强/功能）；
  5. 分别查间隙和爬电，取同时满足的最小值，再留工艺余量。

5. 距离不足的补救

  • 开槽/挡墙：把爬电路径拉长，槽宽/挡墙高度按标准要求；
  • 灌封/涂覆：改变污染条件或隔离路径，需验证工艺可靠性；
  • 换高 CTI 材料：降低爬电要求，但阻燃剂常拉低 CTI；
  • 反查：先定空间再反推可承受电压，评估是否够用。

6. 常见坑

  • 宽压产品按 240V 插值，不按 250V 档——应直接按 250V 档查；
  • III 类设备“不用查距离”——SELV 不成立时仍要按危险电路处理；
  • 海拔只改间隙不改爬电——爬电不随海拔修正（教学逻辑）；
  • 功能绝缘按基本绝缘查——功能绝缘按失效后果单独定；
  • V-0 材料 CTI 可能很低——阻燃和抗起痕是两回事。
