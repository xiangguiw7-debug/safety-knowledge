EMC 系统课程

EMC = 发射（不干扰别人）+ 抗扰（不被别人干扰）。本课程讲清每个试验项目“测什么、从哪来、怎么改”。

1. EMC 的底层逻辑

任何干扰都有三要素：源 → 耦合路径 → 受害对象。整改也只有三条路：消灭源、切断耦合、加固受害对象。

  • 发射 = 我的设备是源，别人是受害对象；
  • 抗扰 = 别人是源，我的设备是受害对象；
  • 耦合路径：传导（走线/电源线/地线）和辐射（空间/线缆天线效应）；
  • 标准只测“结果”，设计要管“机理”——所以先懂机理再整改。

2. 发射类项目

2.1 传导发射（CE，150kHz–30MHz） 深度页 →

测什么：电源端口的骚扰电压，用 LISN 测量，限值分准峰值/平均值。

从哪来：开关频率及其谐波（差模），以及开关节点对地/散热器的共模电流。

怎么改：X 电容抑制差模、共模电感抑制共模、Y 电容提供对地回路（注意泄漏电流限制）、输入 π 滤波、开关节点缓坡、屏蔽散热器。

2.2 辐射发射（RE，30MHz–1GHz+） 深度页 →

测什么：设备向空间的辐射场强，含天线与线缆的贡献。

从哪来：大电流环路（di/dt 环路）、开关节点对地电位、连接线缆作为“天线”辐射共模电流。

怎么改：最小化环路面积、完整地平面、开关节点远离 I/O、线缆加共模扼流/屏蔽、晶振展频、接口滤波。

2.3 谐波与闪烁（IEC 61000-3-2 / -3-3）

测什么：电源输入电流的谐波成分与电压闪烁。

从哪来：整流桥 + 大电解电容的窄脉冲充电电流。

怎么改：有源 PFC、无源填谷/电感滤波；大功率设备基本必须 APFC。

3. 抗扰类项目

3.1 ESD（IEC 61000-4-2） 深度页 →

测什么：接触放电 ±2/4/6/8kV、空气放电 ±2/4/8/15kV（等级视标准）。

机理：亚纳秒上升沿，主要沿缝隙、连接器、按键进入；对数字电路复位/死机影响大。

怎么改：接口加 TVS、缝隙下不放敏感走线、外壳接地、I/O 与地之间加 Y 电容、按键/触摸走线保护。

3.2 浪涌（IEC 61000-4-5）

能量最大的抗扰项目，详细内容见雷击浪涌详解：MOV/GDT/TVS 多级防护、退耦、泄放路径。

3.3 EFT（IEC 61000-4-4） 深度页 →

测什么：5/50ns 脉冲串，叠加在电源/信号线上。

从哪来：继电器、接触器、电机换向。

怎么改：电源口共模电感 + X/Y 电容、信号线屏蔽与滤波、敏感芯片复位/看门狗、软件滤波。

3.4 工频磁场（IEC 61000-4-8） 深度页 →

测什么：50/60Hz 磁场对含磁敏元件（霍尔、CRT、传感器）设备的影响。

怎么改：远离变压器/电机、磁屏蔽、传感器布局方向、软件数字滤波。

3.5 电压暂降与短时中断（IEC 61000-4-11） 深度页 →

测什么：输入电压跌落 0%/40%/70% 若干周期，设备不得损坏或危险。

怎么改：输入储能电容 hold-up 时间、欠压复位阈值、掉电保存、状态机安全恢复。

3.6 项目深度页（发射 + 抗扰）

🔌 传导发射

频段限值、差模/共模来源、滤波整改。

📡 辐射发射

天线机理、环路最小化、屏蔽与展频。

⚡ ESD 静电放电

波形、等级、硬件与软件整改。

🔁 EFT 脉冲群

脉冲串、滤波、复位与通信兜底。

🧲 工频磁场

等级、磁敏元件、屏蔽与布局。

📉 电压暂降

hold-up 设计、欠压检测与恢复。

4. 滤波与接地设计（安规 × EMC 的交叉点）

  • X 电容：跨 L-N 抑制差模；故障时可能短路，前面要有保险丝；
  • Y 电容：跨 L/N-地抑制共模；容量受泄漏电流限制——EMC 要的“越大越好”和安规的“越小越好”必须平衡；
  • 共模电感：对差模几乎无影响，专门对付共模；注意饱和与漏感；
  • 地平面：完整地平面减小回路电感；开槽会切断回流路径，等于“制造天线”；
  • I/O 滤波：连接器处就近放滤波与 TVS，走线先滤波再进板；
  • 开关节点：减小 di/dt 环路、加吸收、缓坡驱动、远离敏感区。

5. 实战整改清单

  • 先确认是差模还是共模（拔线/换线长/加共模电感判断）；
  • 一次只改一个变量，逐项复测，避免“改一堆不知道谁起作用”；
  • 滤波元件靠近源头/端口，而不是靠近芯片；
  • 环路面积最小化：电源、开关、晶振、I/O 四类回路；
  • 线缆处理：屏蔽层单端/双端接地按信号类型，加磁环/共模扼流；
  • 软件兜底：看门狗、数字滤波、重试机制，但不能替代硬件设计；
  • 记录整改前后频谱/波形，形成“问题-措施-验证”闭环。
