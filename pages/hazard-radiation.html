辐射危险深度页

光、激光、射频、电离辐射四类，各自有标准、分级和监管路径。

1. 光生物安全

灯具的紫外/可见（蓝光）/红外辐射按 IEC 62471 分 RG0–RG3。蓝光危害针对视网膜，儿童灯具要求更严；驱动电流、光谱、光学设计共同决定等级，必要时加滤光、遮罩或标签。

详见光生物安全知识卡。

2. 激光安全（IEC 60825-1）

  • 按波长、功率/能量、可达性分 Class 1–4；
  • Class 1 正常使用安全；Class 2 可见光眨眼保护；Class 3/4 需要工程防护；
  • 高等级要求：防护罩、联锁、钥匙开关、警告标签、光束终止器；
  • 激光笔、投影、3D 打印、测距模组都适用。

3. 射频暴露（SAR）

  • 无线设备（手机、穿戴、路由器）按 SAR 限值考核（IEC 62209 / 62479）；
  • SAR 与发射功率、天线位置、距离、占空比有关；
  • 欧盟 RED、美国 FCC 都有射频暴露评估要求；
  • 天线靠近人体部位的产品（耳戴、手环）尤其敏感。

4. 电离辐射（医疗 X 射线等）

  • X 射线设备按 IEC 60601-1-3 考核剂量、屏蔽与安全联锁；
  • 监管路径：中国 NMPA、美国 FDA、欧盟 MDR，注册文件含辐射安全资料；
  • 不是“有屏蔽就行”，还要验证泄漏剂量率和警示装置。

5. 设计自查清单

  • 先确认产品是否有辐射源：光源、激光、射频发射器、X 射线；
  • 选对应标准做分级或测量，而不是“感觉安全”；
  • 标签、防护罩、联锁在结构设计阶段就预留；
  • 医疗辐射设备尽早对接监管注册要求。
