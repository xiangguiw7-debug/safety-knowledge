产品绝缘判定与设计

把一个产品的防电击拆成五个动作：判断类别 → 逐处定绝缘 → 查距离 → 定耐压 → 测泄漏。逆向分析（对着样品判断）和正向设计（对着图纸定方案）用的是同一套逻辑。

⚠️ 本页为重建版本 原页面在文件编码事故中损坏且无备份，本页内容依据站内 knowledge/learn 等页面的同主题素材整理，核心逻辑与原文一致，个别表述可能有出入，请以标准原文为准。

1. 五步法总览

步骤做什么关键输出关联页
① 判断类别确定产品防护类别（I / II / III 类）与供电方式防护策略、距离与耐压的查表前提产品类别
② 逐处定绝缘对每一处带电体到可触及件的路径判定绝缘层级基本 / 附加 / 双重 / 加强绝缘清单双重绝缘判定
③ 查距离按工作电压、污染等级、材料组查爬电与间隙最小间距要求爬电 / 间隙
④ 定耐压按绝缘类型与工作电压确定试验电压并验证耐压测试方案耐压测试
⑤ 测泄漏测量接触电流 / 泄漏电流，确认不超限值泄漏合规结论泄漏电流

2. 第 1 步：判断产品类别

类别防护思路典型判定
I 类接地 + 基本绝缘，接地失效时基本绝缘兜底有保护接地端子 / 三芯电源线
II 类基本 + 附加（双重）或加强绝缘，不依赖接地无接地、外壳为双重/加强绝缘结构
III 类由 SELV 供电，通常不按市电距离要求由安全特低电压源供电

先定类别再谈绝缘：类别的判断决定了后面所有距离、耐压、泄漏的查表前提。

3. 第 2 步：逐处定绝缘

对每一处"带电体 → 可触及件"的路径，判定它需要承担几道防护：

层级保护作用典型理解
基本绝缘正常工作防触电带电体与可触及件之间的基础绝缘，失效后需附加防护兜底
附加绝缘基本绝缘失效后的第二道防护II 类结构中可触及面与基本绝缘之间的绝缘
双重绝缘基本 + 附加两层分别承担一道防护
加强绝缘单层达到双重绝缘同等安全水平距离与耐压按标准加强要求，不能任意"加厚就算"
  • 能限压就先限压：SELV 从源头消除危险；
  • 距离不足时靠开槽、挡墙、灌封、材料升级补救；
  • 带电部件不可徒手触及：外壳、盖板、防护罩通常需要工具才能打开。

4. 第 3 步：查距离

A
电气间隙（clearance）按系统电压 + 过电压类别 → 冲击耐受 → 海拔修正查空气最短距离。详见 电气间隙深度页。
B
爬电距离（creepage）按工作电压 + 污染等级 + 材料组（CTI）+ 绝缘类型查沿面距离。详见 爬电距离深度页。

查表时同时满足间隙与爬电，取较大者，再留工艺余量。

5. 第 4 步：定耐压

按绝缘类型与工作电压确定试验电压：AC/DC 选择、试验时间、判定标准参见 耐压测试深度页 的"5 步法"。

教学速记：基本绝缘示例 1500V AC，加强绝缘示例 3000V AC（以具体产品标准为准）。

6. 第 5 步：测泄漏

测量接触电流 / 泄漏电流，确认不超产品标准限值；Y 电容对地泄漏电流可用 I=2πfCV 估算。详见 泄漏电流深度页 与 泄漏电流估算器。

7. 常见误区

  • "有塑料壳就是双重绝缘"——还要满足附加绝缘的爬电/间隙与耐压；
  • "III 类就不用隔离"——SELV 源本身必须满足隔离与限压；
  • "工具才能打开"不等于随便加个十字螺丝就合规——工具定义、可拆卸部件判定以产品标准为准；
  • 先定距离再定耐压、先定类别再定距离——顺序反了容易漏项。
