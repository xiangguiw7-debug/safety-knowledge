产品类别（Class）

决定防触电结构：I 类靠接地、II 类靠双重绝缘、III 类靠 SELV 供电。

什么是产品类别（I / II / III）？

Ⅰ 类靠“保护接地 + 基本绝缘”兜底；Ⅱ 类靠“基本 + 附加”或加强绝缘，不依赖接地；Ⅲ 类由 SELV 供电，危险电压在电源侧。类别决定测什么：Ⅰ 类测接地连续性，Ⅱ 类测双重绝缘耐压，Ⅲ 类验证 SELV 隔离。

工作电压

250 V

工作电压怎么取？

取绝缘两端实际承受的最高持续电压（交流有效值；医疗标准也允许按直流值查表）。爬电距离按该电压查表（IEC 60664-1 按污染等级 + 材料组；产品标准表按各自分栏）；电气间隙在 IEC 60664-1 依据下按额定冲击电压查表。本工具会在表格档位之间“取不小于工作电压的最小档”，比插值更保守。全球电压与插头见全球电压速查。

查表依据（决定用哪套表）

IEC 60664-1 绝缘配合是基础标准：爬电距离按污染等级（PD1–PD4）+ 材料组（CTI）查表，电气间隙按额定冲击电压（由系统电压 + 过电压类别得到）查表，海拔 >2000 m 只放大间隙。产品标准表（灯具第 11 章 / 医疗 8.7.3）给的是各自产品口径的简化表，认证 / 型式试验按产品标准；设计与通用核算建议按 IEC 60664-1。

IEC 60664-1 参数

爬电距离看工作电压 + 污染等级 + 材料组；电气间隙看额定冲击电压（系统电压 + 过电压类别）+ 海拔。加强绝缘的间隙按下一档冲击电压取值，爬电按基本绝缘的 2 倍。

灯具标准里，爬电距离和电气间隙分别查什么？

同一张表里两列是不同量：爬电距离按材料 PTI（≥600 / <600）分栏、并区分基本 / 附加 / 加强绝缘；电气间隙只按绝缘类型分栏，与 PTI 无关——所以同一条件下两者数值通常不同（例如 250 V、PTI < 600、基本绝缘：爬电 2.5 mm，间隙 1.5 mm）。此外表11.2 用额定脉冲电压再校核一次电气间隙，且要求爬电距离不小于该间隙。使用环境属于几级污染，用污染等级判定器判定，判定结果会在这里回显并与表格的基准条件（PD2）交叉核对。

防护方式（MOPP / MOOP 数量）

医疗标准按“几道防护”查表：患者防护（MOPP）比操作者防护（MOOP）严。

该要几个 MOPP / MOOP？

网电源部分到应用部分（患者可接触）通常要求 2 MOPP；网电源部分到操作者可触及部分按 1–2 MOOP；应用部分到外壳按 1 MOPP。数量由绝缘路径和单一故障分析决定，不是自己选的。判定见MOPP / MOOP 深度页。

材料组（CTI）

材料组（CTI）怎么理解？

CTI（相对漏电起痕指数）用 IEC 60112 滴液试验测得，衡量材料抗表面漏电起痕的能力；材料组按 CTI 分 Ⅰ / Ⅱ / Ⅲa / Ⅲb，决定爬电距离查表的列。注意：V-0 阻燃常拉低 CTI，同一树脂不同牌号可能差一组，正式设计以供应商 CTI 报告为准。常见塑料典型区间见材料库。

绝缘类型

爬电距离与电气间隙是两个不同的量：爬电看材料组（CTI / PTI）与污染等级，间隙看绝缘类型或额定冲击电压——所以同一条件下两者数值通常不同，不能互相套用。加强绝缘：IEC 60664-1 按“爬电 = 基本 ×2、间隙取下一档冲击电压”。

四种绝缘类型怎么区分？

功能绝缘只管正常工作（工程上多按基本绝缘从严核对）；基本绝缘是第一道防触电；附加绝缘是第二道；加强绝缘一道顶两道。取值按所选依据查表：IEC 60664-1 里附加绝缘与基本绝缘同值、加强绝缘爬电为基本绝缘 2 倍、间隙取下一档冲击电压；产品标准表可能另有专列，必须按表查、不要用“×2 基本”估算。判定细节见双重绝缘判定与MOPP / MOOP。

一句话总结

污染等级描述的是绝缘表面会遇到什么：PD1 洁净干燥；PD2 允许干燥的非导电污染与短暂凝露；PD3 是导电污染或反复凝露；PD4 是雨淋、持续水膜或导电尘埃造成的持久导电。把它当作设计起点——最终仍以适用产品标准为准。

四个等级怎么分

PD1洁净干燥 · 无有效污染
PD2干燥非导电污染 + 短暂凝露
PD3导电污染 / 反复凝露
PD4持久导电（雨、水膜、导电尘埃）

从左到右：绝缘表面导电的可能性递增。判的是绝缘表面的微观环境，不是整个房间或厂区。

判定原则与常见坑

  • 判的是绝缘处，不是房间：同一个工厂里，受控柜内可以是 PD2，而室内产品在冷壁、连接器、PCB 边缘也可能凝露到 PD3；
  • IP 等级 ≠ 污染等级：外壳能限制进入，但不能直接换算成某个污染等级；还要看凝露、导电沉积、开孔、维护方式；
  • 只有合格的涂覆 / 灌封才算：IEC 60664-3 对涂层/灌封有材料、覆盖、工艺与试验要求；普通三防漆或“随便封一下”不能当作 PD1；
  • 按正常使用中最不利的可信条件：把温度循环、停机时段、清洗液、工艺导电粉尘都算进去；
  • 产品标准优先：产品标准规定了污染等级或外壳条件时，以产品标准为准——灯具产品标准第 11 章的距离表以污染等级 2 为基准（没有 PD3 / PD4 列），医疗表 11 / 表 12 同样按污染等级 2 给出；
  • PD4 不能直接查表：标准表只给到 PD3；PD4 环境应通过外壳 / 密封 / 涂覆降低微观环境等级后再查表。

判绝缘处，不是判房间

污染等级针对的是绝缘路径紧邻的那一小块环境。一个工厂里可以有洁净受控的柜内环境；反过来，室内产品在冷壁、连接器、PCB 边缘同样可能凝露。判断时要按正常使用中最不利的可信条件：温度循环、停机时段、清洗液、工艺导电粉尘、盐类残留都要算进去，并注意设备所在行业名称不能直接决定等级。

PD2 与 PD3 的实务分界

PD2 适用于“污染本身干燥不导电，且导电只与偶发凝露同时短暂出现”的场合；PD3 的关键在于：污染自己就是导电的（金属屑、盐、碳粉、离子残留），或者受潮反复发生，按正常使用预期足以让干燥沉积物变导电。这一条是认证里最容易被判错的地方——同一个产品，电气柜内可以是 PD2，而没做防护的室内产品也可能落到 PD3。

涂覆 / 灌封只在“合格”时才算

IEC 60664-3 规定了通过涂覆、灌封或模压实现的永久性保护：材料、覆盖范围、工艺控制与试验都要成立，受保护区域才可按更清洁的微观环境取值。普通三防漆、来路不明的涂层、有气泡或覆盖不全的灌封都不能当作 PD1；另外要复核老化、附着力、可修补范围，以及产品标准是否接受这种做法。

判定结果怎么影响爬电设计

污染等级是查爬电距离的输入之一，有时也会带来最小电气间隙的下限。绝缘表面越容易导电，需要的表面路径就越长：PD1–PD3 把结果带进间距工具，再按适用产品标准核对；PD4 通常要求更好的环境防护或产品专用的结构 / 试验方法。

工程师在哪里用到

  • PCB 爬电设计：在查市电、直流母线或隔离电路的爬电表之前，先把污染等级定下来；
  • 工业控制柜：检查粉尘、切削液雾以及不加热停机时段是否把环境从 PD2 推到 PD3；
  • 户外设备：把“外壳外的天气”和“绝缘路径处的实际条件”分开判——IP65 灯具内部可能比外部干净，而灯具标准的距离表以污染等级 2 为基准，PD3 要改用 IEC 60664-1 的 PD3 列或按 IEC 60664-3 降低绝缘处微环境；
  • 涂覆 / 灌封组件：确认保护是按 IEC 60664-3 验证过的，而不是“涂了就按干净算”。

常见问题

污染等级到底是什么？

它是描述绝缘微观环境受污染程度的数字（PD1–PD4），从“洁净干燥”到“雨、导电尘埃等造成持久导电”，用于确定爬电距离，某些情况下也影响最小电气间隙。

PD2 和 PD3 怎么区分？

PD2 一般只有非导电污染，偶尔凝露会造成短暂导电；PD3 要么本身有导电污染，要么因反复受潮使干燥的非导电污染变导电。

PD2 就等于室内吗？

不是。污染等级判的是绝缘处的微观环境：室外设备的外壳内可以是 PD2，而室内不加热的产品也可能因为粉尘 + 反复凝露达到 PD3。

有 IP 等级就能定污染等级吗？

不能直接换算。外壳能限制粉尘和水的进入，但污染等级还取决于凝露、导电沉积、开孔、维护方式，以及适用产品标准的规定。

涂了三防漆就能按 PD1 算吗？

不能一概而论。IEC 60664-3 对涂覆 / 灌封的型式、覆盖与试验有要求；只有满足相应保护类型与证据时，受保护区域才可按更清洁的等级取值，未覆盖处仍按环境判定。

PD4 能直接查爬电表吗？

标准表通常只给到 PD3。PD4 一般要先通过外壳、密封、灌封、排水、除湿等把绝缘处的污染降下来；或按产品标准规定的专门结构与方法评估。

产品标准已经规定了污染等级，怎么办？

以产品标准为准。本判定器只能帮你检查环境假设是否合理，不能覆盖产品标准规定的污染等级、外壳条件或试验要求——比如灯具产品标准第 11 章的距离表就固定以污染等级 2 为基准。

防火试验手册：灼热丝 / 针焰 / 球压

三个试验是一个组合，回答三个问题：会不会被点着？点着后传不传播？受热会不会变形？

为什么必须做这些试验

电子产品内部最常见的起火源不是“着火”，而是接触不良、过载、短路产生的局部高温。安规防火的思路是：即使内部出了故障，外壳和支撑材料也不能成为“助燃剂”和“传播通道”。因此不是测“材料烧不烧”，而是测三件事：

  1. 被热源点着后能不能自熄（灼热丝）；
  2. 被外部小火焰点着后会不会蔓延（针焰）；
  3. 受热受压后会不会变形到带电件位移、爬电失效（球压）。

灼热丝试验（IEC 60695-2-11 / GB/T 5169.13）

方法：镍铬灼热丝（常见 Ø4mm）加热到设定温度（常用 550 / 650 / 750 / 850 / 960°C），以约 1N 的力顶住样品表面，保持 30s，观察是否起燃、燃烧持续时间、是否滴落。

合格判据（教学表述，以标准为准）：

  • 移开灼热丝后，火焰在 30s 内自行熄灭；
  • 燃烧滴落物没有引燃铺底物（绢纸 / 松木板）；
  • 样品未发生持续燃烧。

GWFI / GWIT 是什么：GWFI（灼热丝可燃性指数）= 三个样品都通过 30s 判据的最高温度档；GWIT（灼热丝起燃温度）= 材料持续起燃的判定温度（教学理解：比“不持续起燃的最高温度”高 25K）。产品标准常直接写“GWFI 750 / GWIT 775”这类要求。

温度档怎么定：由产品标准条款和部件的起火风险决定——电源入口、发热件附近风险高取高档；不是“越高越好”，过高要求会逼你换材料。

针焰试验（IEC 60695-2-2 / GB/T 5169.5）

方法：丁烷/丙烷标准针焰（火焰总高约 12mm±1mm，喷管内径约 0.5mm），燃烧器轴线与水平面约 45°，火焰尖端接触样品表面/边缘；施加时间常见 5 / 10 / 20 / 30s（由产品标准规定）；样品下方约 200mm±5mm 处放绢纸+白松木板铺底层，观察是否蔓延、滴落物是否引燃。火焰需先校准：100°C±2°C 升至 700°C±3°C 约 23.5s±1.0s。

判据（教学）：火焰在规定时间内熄灭、滴落物不引燃铺底物、烧蚀范围有限。

体系试验/指标说明
欧标 / IEC针焰（IEC 60695-2-2）直接模拟小火焰引燃后的传播
美标 / ULUL 94（垂直/水平燃烧）+ HWI + HAI没有直接对应针焰，用材料引燃指标组合评估

球压试验（IEC 60695-10-2 / GB/T 5169.21）

方法：直径 5mm 钢球压在样品上，约 20N 力，试验温度按部件位置（常见 125°C，内部支撑件 75°C），保持 1h。

判据：撤压冷却后测量压痕直径，≤ 2mm 为合格。2mm 的意义：防止外壳/支撑件受热变形后，带电件位移、爬电距离缩小到危险程度。

常见坑：压痕要等样品冷却后再测（热态回弹会误判）；薄壁样品和嵌件位置影响结果；材料数据表上的“耐温”不能替代球压实测。

常见误区

“V-0 材料就不需要灼热丝”——V-0 是材料燃烧等级，灼热丝验证的是“故障热源下的自熄”，两者不是一回事；“温度档越高越安全”——档位由标准和风险决定，定高了反而选不到材料；“球压过了就说明耐温”——球压只管变形，RTI 管长期老化，两个都要看。
