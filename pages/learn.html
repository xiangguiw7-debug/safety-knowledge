学习地图（按危害组织）

安规不是名词集合，而是对七类危害的防护体系。先建框架，再按危害逐项深入。

按目标学习

🇨🇳 我要过 CCC / 国内认证

  1. 防电击（四模块）是地基
  2. 行业筛选找产品类目
  3. 标准文件核对 GB 原文
  4. 计算工具估算间距耐压
  5. 全球认证看 CCC 要求

🌍 我要做出口

  1. 全球电压定市场
  2. 全球认证定体系
  3. 标准文件找 IEC/EN
  4. EMC/环保认证一起规划
  5. 计算工具做设计估算

🔌 我要设计电源 / 充电器

  1. 爬电与间隙
  2. 耐压与浪涌；泄漏、接地、SELV、绝缘配合
  3. 能量与限能、防火
  4. 材料库选外壳骨架
  5. 计算工具（电源预设）

🎯 我要入行 / 面试

  1. 标准导读+防触电逻辑
  2. 按路径过七大危害
  3. 补充知识补概念
  4. 答题测验自检
  5. 计算工具练手算

推荐学习路径

建立框架

标准导读 + 防触电五道防线 + 三大认证类型。

防电击（最重要，花最多时间）

电气间隙 → 爬电距离 → 绝缘与耐压 → 泄漏电流/接地 → SELV → 过电压与浪涌防护。

能量危险

限能电路、保险丝、电池能量、电弧。

防火与热量

阻燃材料、灼热丝、温升限值、热失控。

机械与辐射

联锁防护、安全距离；光生物、射频暴露。

化学与环保

RoHS/REACH/WEEE、无卤、能效。

对到认证

安全 / EMC / 环保三类认证怎么考、怎么查。

自检

计算工具 + 分模块测验。
