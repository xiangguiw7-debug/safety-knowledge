电源设计安规专题

开关电源（适配器/充电器/驱动）是安规最集中的品类：输入到输出的隔离链路上，每一步都同时影响安全、EMC 与成本。

1. 初次级隔离链路（整张图先立起来）

从输入到输出，隔离边界上每一段都要同时满足爬电间隙绝缘：

  • 输入侧：保险丝 → EMI（X/Y 电容、共模扼流圈）→ 整流桥 → 大电容 → 开关管；
  • 隔离边界：变压器（绕组间隔离）、光耦/隔离 IC（信号隔离）、Y 电容（共模电流返回路径）；
  • 输出侧：次级整流 → 输出电容 → 可触及输出端（常按 SELV 处理）。

判断标准：输出是否可触及、是否 SELV、是否需要接保护地——由产品类别与SELV 条件决定。

2. 变压器安规要点

  • 绕组爬电/间隙：初次级绕组间按加强/双重绝缘查表（含磁芯的路径），挡墙/三层绝缘线按标准；
  • 层间绝缘：绕组层数、绝缘胶带厚度与等级（如三层绝缘线 TEX-E 等）按 62368/60950 要求；
  • 磁芯接地：磁芯与初次级间跨 Y 电容（常见），磁芯本身要满足对输出/外壳的间距；
  • 温升：绕组温升按标准限值（磁芯/绕组/绝缘材料），用温升估算粗算再实测；
  • 材料：骨架/绝缘材料 CTI 与阻燃同时满足（CTI 卡）。

3. Y 电容：EMC 想要大，安规想要小

Y 电容跨初次级/对地，是共模 EMI 的返回路径，但容量越大对地泄漏电流越大：I = 2πfCV。

  • 先算泄漏：230V/50Hz 下，1000pF ≈ 0.072mA、4700pF ≈ 0.34mA——对照产品限值（II 类常见 0.25mA 接触电流，I 类对地另计）；
  • 用泄漏电流估算器正算/反算；
  • Y 电容必须用认证元件（Y1/Y2），失效模式要"开路"。

4. 浪涌防护：MOV/GDT/TVS 三级配合

器件位置特点注意
MOV 压敏电阻第一级（输入 L-N）能量大、响应慢、会老化老化短路需配保险丝；钳位电压与耐压协调
GDT 气体放电管第一级（对地/共模）泄放大、响应慢、有续流续流要靠后级/断电消除
TVS 瞬态抑制末级（精确钳位）响应快、能量小不能单独扛大浪涌

深度见雷击浪涌章节；测试按 IEC 61000-4-5（浪涌 SOP）。

5. 保险丝：不只是"额定电流"

  • 额定电流：约 1.25–1.5 × 稳态（含温升降额）；
  • 分断能力：≥ 输入侧预期短路电流（电网短路电流可能很大）；
  • I²t：开机浪涌（大电容充电）的 I²t 必须小于保险丝熔断 I²t，否则一开机就烧；
  • 位置：串在输入最前（L 线，按标准），覆盖整流桥短路等故障路径；
  • 工具：保险丝选型速查。

6. 宽压 100–240V 设计判定

  • 系统电压按最高档（230/250V 档）查间隙与过电压类别；
  • 工作电压按最高输入档确定爬电距离（240V 档按 250V 查表）；
  • 插头/认证按目标市场分别处理（全球电压速查）；
  • 输入电压范围与降额（低温/低压满载）一并验证。

7. 常见坑

  • 阻焊层/三防漆当爬电——不行，爬电按裸露绝缘表面；
  • Y 电容随意加大压 EMI——泄漏超标；
  • 变压器磁芯直接贴外壳——间距不足；
  • 保险丝位置在整流后——不保护整流桥前短路；
  • 只算额定状态温升——要测最不利（满载+高温+低压）。

8. 隔离 vs 非隔离：LED 灯具驱动怎么选（灯具行业最常问）

LED 灯具的驱动电源分隔离型和非隔离型两大类。先记住一句话：隔离 = 有变压器把输入输出分开；非隔离 = 没有变压器，输出端与市电共地。这个结构差异直接决定安全等级、成本、体积和认证难度。

对比项隔离型驱动非隔离型驱动
结构高频变压器 + 反馈（光耦/绕组）Buck/Boost 降压，无变压器
输出是否带电次级与输入隔离，可做到 SELV 安全低压输出与市电共地，带危险电压
安全性输出可触及（符合 SELV 时）；金属外壳灯具可安全使用整板算带电部件，可触及性完全靠外壳/结构保证
成本高（变压器、光耦、材料多）低（省变压器，电路简单）
体积大（变压器占空间）小，便于内置
效率略低（变压器损耗，一般仍达标）略高（少一级损耗）
认证重点变压器初次级间距、绕组隔离、耐压外壳绝缘（球压/灼热丝/厚度）、铝基板与可触及件距离
典型应用金属外壳筒灯/面板灯、户外灯、路灯、出口欧美成品灯塑料外壳球泡灯、灯带、内置式低成本灯具

先懂原理：隔离的本质是"电流隔离"（galvanic isolation）

  • 定义：隔离 = 输入与输出之间没有任何直接导电通路，能量靠磁场（变压器）、光（光耦）或电场（电容隔离）传递。非隔离 = 输入输出共用一个参考地，电流可以直通；
  • 为什么需要隔离？三个理由：① 安全——把人（用户/患者）与危险电压隔开，输出可做成 SELV；② 消除地环路——隔离后输出浮地，不与其他设备形成地电位差回路（工控/医疗/仪表场景尤其重要）；③ 噪声抑制——变压器阻断共模传导路径，有助于 EMI 达标；
  • 隔离怎么实现：高频变压器（磁耦合，电源主力）、光耦（只传信号，做反馈隔离）、电容隔离（小功率信号隔离）；
  • 拓扑对应：非隔离主流是 Buck 降压（小功率低成本）；隔离主流是 Flyback 反激（几十瓦起，变压器同时做储能与隔离）、中功率以上用 LLC/Forward 等。

注意：隔离的价值不只是"安全等级"，还有"浮地"与"共模阻断"——所以工业控制、医疗设备里很多隔离电源并不是因为输出会被人摸到，而是为了信号纯净和消除地环路。

隔离型驱动：安全优先，贵在"隔"

  • 原理：市电整流后经高频变压器耦合到次级，初次级之间无电气连接；反馈靠光耦或辅助绕组，保证稳压且隔离；
  • 优点：次级可做成 SELV 安全低压——灯体、铝基板、可触及金属件都不带危险电压，金属外壳灯具随便用；安规结构清晰（初次级之间做加强绝缘即可），认证难度低、通过率高；输出稳定、纹波小；
  • 缺点：成本高（变压器+光耦）、体积大（塞不进小灯头）、效率比非隔离低 2–4 个百分点（量级，视设计）；
  • 安规要点：变压器初次级之间要满足加强绝缘的爬电/间隙（市电档，见 间距工具）；变压器本身要认证（IEC 61558 / 61347）或随整机做随机测试；次级如做 SELV，输出限值与隔离都要验证。

非隔离型驱动：便宜高效，但"带电"要结构来扛

  • 原理：Buck（降压）直接斩波输出，输入输出共地——输出负端与市电 N 相连，输出端和灯珠铝基板都是带电部件；
  • 优点：省变压器，成本低、体积小、效率高，特别适合内置式小功率灯具（球泡、灯带）；
  • 缺点：整个次级都带电——灯珠、铝基板、焊点都不能被触及；金属外壳灯具基本不可用（除非外壳再隔离，得不偿失）；对灯具结构件的绝缘要求极高；
  • 安规要点（关键）：可触及性完全靠外壳承担——塑料外壳要满足球压（高温不变形）、灼热丝/针焰（防火）、壁厚与加强绝缘等级；铝基板到外壳内壁的距离按带电部件对可触及件查爬电/间隙；金属散热器与铝基板之间的距离是高频不合格点（爬电/间隙不足）；
  • 误区澄清：非隔离 ≠ 不合格。只要外壳绝缘与距离满足 IEC 60598-1（GB 7000.1）的可触及带电部件判定，非隔离完全可以合规——塑料球泡灯绝大多数就是非隔离。

选型速查：什么时候选哪个

场景推荐原因
金属外壳灯具（筒灯/面板灯/路灯）隔离金属可触及，非隔离会让整个灯体带电
户外灯具 / 潮湿环境隔离凝露/水汽降低绝缘能力，隔离更稳
出口欧美做 CE/UL 认证隔离优先认证结构清晰、通过率高、沟通成本低
塑料外壳球泡 / 灯带 / 内置小功率非隔离成本与体积敏感，外壳可保证绝缘
功率 > 30–40W 且要求高效隔离（认真设计）大功率非隔离对外壳要求极高，多数场景不划算

工程提醒：先定"能不能被摸到"，再定隔离与否——可触及金属 → 隔离；全塑料且绝缘距离够 → 非隔离。灯具设计里"铝基板不是绝缘层"，它只是带绝缘覆层的导体，不能当加强绝缘用（安规网最常见的整改项之一）。

三问决策法（结合英文技术文的选型思路）

问 1：输出端会不会被用户摸到？
会（金属外壳、可更换光源、可触及端子）→ 隔离；完全封闭在塑料外壳内且距离够 → 非隔离可谈。

问 2：要不要"浮地"？
输出要与系统/大地隔离（医疗、工控、多设备互联防地环路）→ 隔离；单机独立供电、无地环路问题 → 非隔离可选。

问 3：EMC 与成本怎么权衡？
隔离变压器天然阻断共模传导（EMI 好做），但成本高；非隔离省变压器、效率高，但共模路径直连，要靠共模电感/滤波补救——多数消费灯具选非隔离是"成本换设计工作量"。

三个问题都答完，结论基本就出来了：可触及 + 浮地 + 好认证 → 隔离；封闭 + 独立供电 + 成本敏感 → 非隔离。

常见误区

  • “非隔离效率高就一定好”——铝基板带电，结构不过关照样判不合格；
  • “隔离就绝对安全”——变压器初次级爬电/间隙不足、次级飞线没固定，照样出问题；
  • “非隔离只能做小功率”——可以做，只是外壳与结构要求按功率和可触及性成倍变严；
  • “塑料外壳就万事大吉”——壁厚、球压、灼热丝、阻燃等级、距离都要逐项过；
  • “铝基板可以做绝缘”——它是导体+薄绝缘覆层，只能按"带电部件"对待，绝缘靠外壳和结构。
