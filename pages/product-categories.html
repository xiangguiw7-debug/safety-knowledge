产品品类安规知识库

九个核心品类的安规知识：先看公共地基（间隙、爬电、耐压、浪涌、IP、防火），再按品类看自己的标准、测试、设计重点和认证路径。

先分清两个“类别”

“产品品类”指家电、IT、灯具等产品门类；“防触电类别”指 I / II / III 类结构。两者不冲突：同一个品类里可以有 I 类、II 类或 III 类产品。结构类别见产品类别结构图。

🏠 家用电器

最经典的安规品类：电机、加热元件、潮湿环境，处处考验泄漏电流与异常工作保护。

核心标准

  • IEC 60335-1 / GB 4706.1：家电通用安全要求；
  • IEC 60335-2 系列 / GB 4706.x：电饭煲、洗衣机、冰箱、吸尘器等各类器具特殊要求；
  • EMC：CISPR 14-1 / 14-2（骚扰与抗扰）、IEC 61000-3-2 / -3-3（谐波/闪烁）；
  • 能效：各国能效标签与最低能效标准（MEPS）。

典型测试

测试目的常见关注点
耐压（介电强度）验证绝缘体系I 类基本绝缘、II 类双重绝缘、III 类 SELV
泄漏 / 接触电流验证摸到外壳是否安全潮湿状态、最不利电源极性
温升验证发热部件与可触及表面电机、加热元件、端子、外壳
异常运行堵转、短路、过载时仍安全电机热保护、保险丝、PTC
湿热试验验证潮湿环境下的绝缘污染等级、爬电距离余量
接地连续性I 类产品接地回路端子防松、接触电阻

设计重点

  • 先判定产品类别（I / II / III），再定绝缘和测试组合；
  • 电机类必须有堵转/过载保护，不能只靠保险丝“碰运气”；
  • 加热元件周围材料要耐热耐燃，球压和灼热丝按标准执行；
  • 潮湿环境按污染等级 2/3 设计，不能按干燥环境查表；
  • 接地端子、内部线、端子排都要有机械固定和防松措施。

认证路径

中国 CCC（目录内）/ CQC（目录外）→ 欧盟 CE（LVD + EMC）→ 美国 UL/ETL → 日本 PSE → 韩国 KC → 澳洲 RCM。家电是 CB 体系最成熟的品类之一，可用 CB 报告转证。

常见坑

  • 按干燥环境设计，湿热试验后爬电不够；
  • 电机堵转无热保护，温升超标甚至起火；
  • 接地端子松动或接触电阻过大；
  • 把“低功率”当成“不用做安规”。

💻 音视频 / IT 设备

音箱、路由器、显示器、笔记本电源等，核心是 IEC 62368-1 的能量源分级思想。

核心标准

  • IEC 62368-1 / GB 4943.1：音视频、信息技术与通信设备安全；
  • EMC：CISPR 32 / EN 55032（发射）、CISPR 35（抗扰）、IEC 61000-3-2 / -3-3；
  • 无线功能：RED / FCC Part 15；
  • 电池：IEC 62133 / GB 31241。

典型测试

测试目的常见关注点
能量源分级确定 ES1/ES2/ES3 与可触及要求端口、内部电路、故障条件
耐压与泄漏验证绝缘与接触电流电源初次级、USB/PoE 口隔离
防火外壳内部起火不烧穿外壳V-0/5VA、开孔尺寸、挡板
温升可触及表面与元件温度充电口、外壳、电池仓
机械应力跌落、推力、悬挂外壳强度、连接器固定
EMC 抗扰ESD、浪涌、EFT、电压暂降接口防护、PCB 布局

设计重点

  • USB、HDMI、PoE 等端口与内部高压电路之间必须算间距；
  • 金属螺钉、散热片不能桥接两层绝缘；
  • 塑料外壳阻燃等级和开孔位置决定防火是否成立；
  • 带电池产品要叠加电池保护与热失控管理；
  • 通信端口要做浪涌/EFT 防护，不能只保护电源口。

认证路径

中国 CCC（目录内）/ CQC → 欧盟 CE（LVD + EMC + RED）→ 美国 FCC + UL → 日本 PSE/TELEC → 韩国 KC → 台湾 BSMI → 澳洲 RCM。

常见坑

  • USB 口与内部高压走线间距不足；
  • 只做电源口浪涌，通信口雷击批量损坏；
  • 防火外壳等级够但开孔过大，挡板失效；
  • 软件更新后安全功能被绕过。

爬电距离 · 耐压测试 · 防火 · 雷击浪涌

💡 灯具照明

从 LED 灯泡到户外路灯，核心是防触电、温升、防尘防水与光生物安全。

核心标准

  • IEC 60598-1 / GB 7000.1：灯具通用安全；
  • IEC 61347 / GB 19510：灯控制装置（含 LED 驱动）；
  • IEC 62031：LED 模块；
  • IEC 62471 / GB/T 20145：光生物安全；
  • IEC 60529 / GB/T 4208：IP 防护等级。

典型测试

测试目的常见关注点
介电强度验证绝缘体系隔离驱动初次级、可更换光源
泄漏电流验证可触及金属潮湿灯具、金属外壳
温升LED 与驱动温升散热、绝缘老化、外壳温度
IP 测试验证户外防尘防水IP44–IP66、密封圈老化
浪涌户外雷击/电网浪涌驱动 SPD、初次级间距
光生物蓝光/紫外/红外危害儿童灯具、高亮度 LED

设计重点

  • 隔离驱动初次级间距不足是耐压/浪涌打火的第一原因；
  • 户外灯具必须做 IP 与浪涌联合设计，不是“加个胶圈就行”；
  • 蓝光危害等级随亮度、光学设计变化，样品阶段就要测；
  • 可更换光源的防触电结构（防触电罩、工具要求）要单独验证；
  • LED 驱动温升直接影响寿命和绝缘，散热要留余量。

认证路径

中国 CCC/CQC → 欧盟 CE（LVD + EMC + ErP 能效）→ 美国 UL/DLC → 韩国 KC → 沙特 SASO（IECEE CB 转证）→ 澳洲 RCM。

常见坑

  • 驱动初次级间距不足，浪涌后打火；
  • 户外灯具没有 SPD，雷击损坏驱动；
  • 儿童灯具忽视蓝光与可触及部件温升；
  • 高 IP 等级但透气阀/排水孔破坏了密封。

雷击浪涌 · IP 防护 · 光生物安全 · 爬电距离

🔌 电源与充电器

开关电源是爬电、间隙、浪涌、安规电容和保险丝知识的综合考场。

核心标准

  • IEC 62368-1 / GB 4943.1：电源安全；
  • IEC 60384-14：X/Y 安规电容；IEC 60127：保险丝；
  • IEC 61558：变压器/电源装置（部分产品）；
  • IEC 61000-3-2：谐波电流；GB/T 17626.5：浪涌；
  • 能效：DOE VI / CoC / 中国能效等级。

典型测试

测试目的常见关注点
爬电 / 间隙初次级隔离变压器、光耦、PCB 开槽
耐压验证绝缘强度基本/加强绝缘、打火位置
泄漏电流验证 Y 电容与共模路径Y 电容容量与泄漏的平衡
温升磁性元件、MOS、外壳满载/短路/异常状态
浪涌雷击/电网瞬态MOV、放电管、初次级间距
短路/过载保护动作保险丝、限流、恒功率

设计重点

  • 初次级隔离间距要按加强绝缘查表，并用开槽/挡墙保证工艺余量；
  • Y 电容容量越大 EMI 越好、泄漏电流越大，要按标准限值平衡；
  • 保险丝必须用认证元件，并放在能切断故障电流的位置；
  • X 电容放电电阻要满足插头拔出后的残余电压时间要求；
  • 能效与待机功耗、安规元件选型一起规划，不要最后才改。

认证路径

中国 CCC/CQC → 欧盟 CE（LVD + EMC + ErP）→ 美国 UL/ETL + DOE → 日本 PSE → 韩国 KC → 台湾 BSMI → 澳洲 RCM。

常见坑

  • 初次级间距只算 PCB 走线，忘了变压器飞线和光耦；
  • Y 电容过大导致泄漏电流超标；
  • 保险丝没认证或位置不对，短路时不断开；
  • 浪涌测试时 MOV 后面没有足够间距，打火短路。

爬电距离 · 电气间隙 · 耐压测试 · 雷击浪涌

🔋 电池与储能

从便携锂电池到储能柜，热失控、运输安全和高压绝缘是重点。

核心标准

  • IEC 62133 / GB 31241：便携式电池安全；
  • UN 38.3：锂电池运输；
  • IEC 62619：工业电池；IEC 62620：储能电池；
  • UL 9540A / GB/T 36276：储能系统热失控与安全；
  • BMS 功能安全：IEC 61508 / ISO 13849 思路。

典型测试

测试目的常见关注点
过充 / 过放保护板动作电芯电压、保护阈值、恢复逻辑
短路切断短路电流MOS、PTC、Fuse 配合
过温热失控前切断NTC 位置、充电温度范围
跌落 / 挤压 / 热冲击滥用后不冒烟起火结构强度、电芯固定
热失控扩散单颗失效不烧穿整包隔热、泄压、外壳防火
运输试验UN 38.3 全套包装、文件、标签

设计重点

  • 保护板不是“有就行”，要验证单一保护失效时仍有第二道保护；
  • 电芯一致性差比单颗电芯性能差更危险；
  • 热失控要按“一颗失效 → 不扩散到整包”设计，隔热和泄压缺一不可；
  • 连接器要防反接、防短路，电池仓要防震动脱落；
  • 运输文件、MSDS、UN38.3 报告和包装要一起准备。

认证路径

便携电池：CB（IEC 62133）、UN38.3、PSE、KC、UL；储能系统：UL 9540A / IEC 62619 / GB/T 36276，按市场分别注册。

常见坑

  • 只做保护板功能测试，没做单一故障；
  • 热失控试验后外壳烧穿或相邻电芯连锁；
  • 运输时把电池当普通货物，缺 UN38.3 文件；
  • 储能柜高压侧爬电/间隙按低压产品设计。

📡 无线设备

蓝牙、Wi-Fi、5G、IoT 设备：射频、EMC、电池与网络安全叠加。

核心标准

  • 欧盟 RED 2014/53/EU；美国 FCC Part 15；加拿大 ISED；日本 MIC/TELEC；
  • 安全：IEC 62368-1 / GB 4943.1；
  • EMC：CISPR 32 / 35；
  • 射频暴露：IEC 62209 / EN 50566（SAR）；
  • 电池：IEC 62133；网络安全：RED 附件 / ETSI EN 303 645。

典型测试

测试目的常见关注点
RF 输出 / 频段验证发射功率与占用带宽天线设计、认证频段
EMC发射与抗扰天线与主板布局、屏蔽
SAR人体射频暴露贴近身体的设备必测
安全充电口、电池、外壳USB 隔离、电池热失控
电池充放电保护快充协议、过温
网络安全固件、通信、隐私默认密码、更新机制

设计重点

  • 天线位置和外壳材料会改变 RF 与 SAR，结构定型后再测；
  • 无线充电线圈周围要控温，金属异物会局部发热；
  • USB 口与电池、主板高压间距不能省；
  • 固件更新不能关闭安全功能，也不能绕过认证状态；
  • 多模设备（Wi-Fi+蓝牙+5G）要按每个无线模块分别看认证。

认证路径

欧盟 CE-RED → 美国 FCC + UL → 加拿大 ISED + cUL → 日本 TELEC/PSE → 韩国 KC → 台湾 NCC/BSMI → 东南亚各国无线注册。

常见坑

  • SAR 评估遗漏，产品贴近身体才被发现；
  • 天线与金属件距离改变导致发射超标；
  • 无线充电过热没有温度保护；
  • 软件更新后射频参数漂移。

EMC 课程 · 电池 · 辐射危险 · 软件安全

🏥 医疗设备

安规要求最严的品类：患者漏电流、MOPP/MOOP、风险管理与生物相容性缺一不可。

核心标准

  • IEC 60601-1 / GB 9706.1：医用电气设备安全；
  • IEC 60601-1-2：医用 EMC；
  • ISO 14971 / GB/T 42062：风险管理；
  • IEC 62304：医疗器械软件；IEC 62366：可用性；
  • ISO 10993：生物相容性。

典型测试

测试目的常见关注点
患者/外壳漏电流接触患者与操作者的电流正常与单一故障状态
介电强度MOPP/MOOP 绝缘应用部分、电源隔离
接地阻抗保护接地有效性I 类医疗设备
EMC不能干扰其它医疗设备抗扰等级更高
风险管理危害分析与控制ISO 14971 全流程文档
生物相容性接触患者材料安全细胞毒性、致敏、刺激

设计重点

  • 患者漏电流限值远严于家电，设计余量至少留 50%；
  • 应用部分（BF/CF）决定绝缘和漏电流要求，先定类型再设计；
  • 所有安全功能都要做单一故障分析，不能只测正常状态；
  • 软件按 IEC 62304 分级，安全相关功能要可追溯；
  • 接触患者材料从选型就要查 ISO 10993，不能最后才送测。

认证路径

中国 NMPA 注册 → 欧盟 CE-MDR（公告机构）→ 美国 FDA 510(k)/PMA → 其它国家按当地注册。医疗不是自我声明，认证周期和文档要求要提前规划。

常见坑

  • 漏电流按家电思维设计，测试才发现超限；
  • 风险分析文档和测试报告对不上；
  • 接触患者部件没做生物相容性；
  • 软件更新后没走变更控制。

🏭 工业机械

除了电气安全，还要懂机械防护、功能安全等级，现场污染等级通常按 3 设计。

核心标准

  • IEC 60204-1 / GB 5226.1：机械电气设备；
  • ISO 13849-1 / IEC 62061：控制系统安全（PL/SIL）；
  • ISO 13850：急停；ISO 13857：安全距离；
  • IEC 60079 / GB 3836：防爆；
  • EMC：IEC 61000-6-2 / -6-4 或产品专用标准。

典型测试

测试目的常见关注点
介电强度 / 接地电气安全基础控制柜、电机、现场接线
EMC现场抗干扰与发射变频器、伺服、通信线
急停响应安全功能可靠复位逻辑、旁路防护
安全距离 / 联锁防止进入危险区开口尺寸、传感器位置
IP 防护粉尘、水、油污控制柜、电机、接插件
功能安全验证PL/SIL 达标MTTFd、DC、结构类别

设计重点

  • 安全距离是算出来的，不是“看着够”；
  • 急停不能只做按钮，要验证断电、断线、复位都安全；
  • 现场粉尘潮湿，污染等级按 3 设计，爬电/间隙要留余量；
  • 变频器/伺服是 EMC 重灾区，屏蔽、接地、滤波一起规划；
  • 危险区域设备要按防爆型式（本安、隔爆等）设计。

认证路径

欧盟 CE-MD（机械指令）+ EMC + 低电压（如适用）→ UKCA → 中国 GB 认证/检验 → 防爆设备按 IECEx / ATEX / GB 3836。功能安全等级要由评估机构确认。

常见坑

  • 防护罩开口过大，手指/工具可伸入；
  • 急停被旁路或复位逻辑不安全；
  • 现场粉尘潮湿却按污染等级 2 设计；
  • 安全回路没有失效模式分析。

机械防护 · 功能安全 · 防爆 · 爬电距离

🔧 电动工具

双重绝缘结构 + 电池保护 + 机械耐久，是电动工具的三座大山。

核心标准

  • IEC 62841 / GB 3883：手持式、可移式电动工具安全；
  • IEC 62133：工具电池包；
  • EMC：CISPR 14-1 / 14-2；
  • 功能安全：ISO 13849（部分工具的安全功能）。

典型测试

测试目的常见关注点
双重绝缘耐压基本 + 附加绝缘外壳开孔、内部金属桥接
温升电机、手柄、电池仓堵转、连续负载
耐久长期使用可靠性开关、碳刷、齿轮
跌落 / 冲击结构强度外壳、电池仓、开关
IP 防护粉尘与水分换向器火花与粉尘隔离
电池充放电过充/过流/过温快充、低温充电

设计重点

  • 双重绝缘的“两层”必须独立，螺钉、金属支架不能桥接；
  • 换向器火花要远离可燃粉尘和外壳开孔；
  • 电池包保护要覆盖过充、过放、过流、过温，不只做短路；
  • 手柄握持区温升直接决定可用性和安全性；
  • 跌落试验后开关、电池连接、绝缘都不能失效。

认证路径

中国 CCC → 欧盟 CE + GS（渠道常见）→ 美国 UL/ETL → 日本 PSE → 韩国 KC → 澳洲 RCM。电动工具在 CB 体系下可转证多个市场。

常见坑

  • 外壳开孔破坏双重绝缘结构；
  • 电池包只有过充保护，没有过温保护；
  • 换向器火花引燃粉尘环境；
  • 跌落试验后电池连接松动。
