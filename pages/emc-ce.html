传导发射（Conducted Emission，CE）

测的是设备“顺着电源线往外送”的骚扰电压，150kHz–30MHz。开关电源的谐波基本都藏在这里。

1. 频段与限值（教学参考）

用 LISN（线路阻抗稳定网络）在电源端口测量，检波方式为准峰值（QP）和平均值（AV），两个都要满足。

频段CISPR 32 Class B 准峰值（示例）平均值（示例）
0.15 – 0.5 MHz66 – 56 dBµV（随频率递减）56 – 46 dBµV
0.5 – 5 MHz56 dBµV46 dBµV
5 – 30 MHz60 dBµV50 dBµV

Class A（工业）限值更宽；具体以适用产品标准和版本为准。

2. 噪声从哪来：差模 + 共模

  • 差模：开关电流纹波在输入环路（整流桥 → 电解电容 → 开关管）形成 L-N 之间的骚扰电压；
  • 共模：开关节点的高 dv/dt 经寄生电容（散热器、变压器初次级、PCB 对地）流到地，再沿电源线流出；
  • 低频段（<1MHz）常以差模为主，高频段（>1MHz）常以共模为主——不是绝对，用“拔线/加共模电感”试验区分。

3. 硬件整改

  • X 电容：跨 L-N，抑制差模；容量与耐压按认证元件选，故障时配合保险丝；
  • 共模电感：抑制共模；注意饱和、漏感，以及 Y 电容的搭配；
  • Y 电容：提供共模回流路径，但容量受泄漏电流限制；
  • 输入 π 滤波：X 电容 + 共模电感 + X 电容，两级之间走线要短；
  • 开关节点：加 RC 吸收、减小 di/dt、驱动缓坡；
  • 散热器：接开关节点电位或接地要一致，避免“漂着”当天线；
  • 布局：开关环路最小化，滤波元件靠近端口，输入地单点汇接。

4. 实战排查顺序

  1. 先看频谱图：超标是窄带尖峰（开关频率谐波）还是宽带包络（共模谐振）；
  2. 窄带 → 差模滤波/展频/开关频率调整；宽带 → 共模路径/屏蔽/接地；
  3. 一次只改一个元件，复测后记录，避免“改了一堆不知道谁起作用”；
  4. 关注温度：热机后滤波电感饱和或电容劣化，限值可能漂移。

5. 常见误区

  • “滤波器越大越好”——电感会饱和、电容会谐振，要按电流与频段选；
  • “只看准峰值”——平均值超了同样不合格；
  • “传导发射是电源口的事”——信号线、负载线也会参与耦合。
