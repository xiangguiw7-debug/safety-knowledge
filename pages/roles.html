岗位化学习路径

不同岗位用安规的方式完全不同：选一条适合你的路。

🔧 硬件工程师

  1. 电气间隙 + 爬电距离（查表闭环）
  2. PCB 安规设计指南
  3. 元器件安全专题
  4. 耐压 + 浪涌（设计与试验）
  5. 计算工具 + 测验

📋 认证 / 合规工程师

  1. 认证流程（CB 转证/工厂检查）
  2. 标准差异矩阵
  3. 全球认证 + 认证向导
  4. 标签与说明书
  5. 标准更新追踪

🛠️ 结构 / 机械工程师

  1. 机械危险深度页
  2. 防护与联锁 + 功能安全
  3. 材料库（CTI/阻燃/RTI）
  4. 环境与可靠性试验
  5. 设计阶段避坑

🎨 设计师 / 产品经理

  1. 设计师必须知道的安规
  2. 防触电五道防线（概念）
  3. 标签与标志规范
  4. 案例库（理解为什么这么设计）
  5. FAQ（快速答疑）
